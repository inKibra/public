# Contributing to inKibra Open Source

Thank you for your interest in contributing!

## Development

```bash
# Install dependencies
bun install

# Run linting
bun run lint

# Type check
bun run check:tsc
```

## Pull Requests

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request

## Code of Conduct

Be kind and respectful to others.
